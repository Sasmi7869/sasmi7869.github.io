✨ What This Tool Does

PlayStation Portal streams games from your PS5 over your local network. By default, the bitrate is set to a level that balances quality and stability. This project provides experimental tools that let you try a higher bitrate, such as the 100 Mbps profile. A higher bitrate can reduce compression artifacts, making text and fast-moving scenes look clearer. However, it also requires more network bandwidth.

Key points

  • Experimental: These tools are not official Sony products. They are community-made and provided as-is.
  • Higher bitrate profiles: The tools help you apply a higher bitrate setting, including a tested 100 Mbps profile.
  • Cross-platform: Tools are available for Windows, macOS, and Linux.
  • Raspberry Pi relay: An optional Ethernet relay setup for Raspberry Pi 4 can help stabilize the connection when using higher bitrates.

If your network is not strong enough, a higher bitrate may cause stuttering or lag. Start with a lower profile and work your way up. The project is intended for users who want to experiment and are comfortable trying new settings.

🖥️ How to Use on Windows

Follow these simple steps to get started on your Windows PC. Make sure your PS5 and PlayStation Portal are turned on and connected to the same network before you begin.

  1. Open the downloaded application on your Windows PC. You can double-click the file to launch it.
  2. Allow the application to communicate over your local network if Windows asks for permission. This is needed so it can find your PlayStation Portal and PS5.
  3. In the application, look for the bitrate setting. Choose a higher bitrate profile, such as the 100 Mbps profile, if you want to try the highest quality. You can start with a lower profile and increase it later.
  4. Apply the setting and keep the application running while you use your PlayStation Portal. The tool works in the background to help the higher bitrate setting take effect.
  5. Test your stream on the PlayStation Portal. If you notice stuttering or lag, go back to the application and choose a lower bitrate profile, or improve your network connection.

If you are using the optional Raspberry Pi 4 Ethernet relay, set it up according to the instructions on the project page. The relay can help provide a more stable connection when using the 100 Mbps profile. Connect your PlayStation Portal to the relay network and keep your Windows PC on the same network to manage the tool.

🔧 Troubleshooting Tips

Here are some common issues and simple solutions. These tips are written for non-technical users.

  • The application does not open: Make sure you extracted the file if it was downloaded as a compressed folder. Right-click the downloaded file and choose Extract All, then open the application from the extracted folder.
  • Windows shows a security prompt: This can happen with downloaded applications. Choose the option to run the application if you downloaded it from the official project link.
  • The stream stutters or lags: A higher bitrate needs more bandwidth. Move your PlayStation Portal closer to your Wi-Fi router, use a 5 GHz network, or try a lower bitrate profile. If you are using the Raspberry Pi relay, make sure it is connected with an Ethernet cable.
  • The application cannot find the PS5 or Portal: Check that all devices are on the same network. Restart your router if needed. Make sure your Windows PC is not connected to a guest network or a different Wi-Fi name.
  • The picture quality does not change: Some games and scenes are harder to improve than others. Also, the Portal may need to be restarted after applying a new bitrate setting. Close and reopen the remote play session on your Portal.
